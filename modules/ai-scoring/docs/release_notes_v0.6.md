# v0.6.0 更新说明

## 本次新增

- 新增 TOPE Mate Practice Score：0–100 产品内部单阶段练习参考分；当前不合成完整 B/C 多阶段考试总分。
- 保留人大官方 B/C 1–6 级描述作为定性锚点，不再将官方等级作为用户输出。
- AI 仅输出各可评估维度的 0–100 分、理由和证据；后端按固定产品权重计算总分。
- 缺少必要证据的维度为 `null`，不按 0 分处理；总分对已评估权重重新归一化。
- 时间控制分由后端根据录音时长和目标时长计算；没有目标时长时不评分。
- B discussion 只有目标考生与至少一位其他考生均有真实发言轮次时才评估互动；考官轮次不算同伴互动。
- 比较键加入算法版本、提示词版本和模型标识，避免跨配置直接比较历史分数。
- 阶段权重根据此前讨论的产品侧内容、组织论证、语言、互动/任务完成和时间控制重点细化；仍属实验性内部权重。
- 新增合成数据算分 demo，明确不代表 AI 评分。

## 官方资料对齐修订

- B 官方截图摘要：话题内容、讨论参与及语用适切、交际任务完成。
- C 官方截图摘要：话题内容与论述、词汇语法及语音语调、时间控制。
- C 评分表标题虽包含“问答”，但截图等级条目没有单列 Q&A 数值权重；模块不虚构官方 Q&A 权重。
