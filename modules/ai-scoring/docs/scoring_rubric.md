# TOPE B/C 评分依据与 Practice Score 规则 v0.6

## 1. 官方依据：按用户上传的评分表截图整理

### TOPE B：陈述与讨论评分标准

用户上传的 B 评分表按 1–6 级描述以下三方面：
1. **话题内容**：是否契合话题要求，能否表达自己的观点，并对他人观点作出反应。
2. **讨论参与及语用适切**：能否自然、积极地参与讨论，语言使用是否适应语境、功能和目的。
3. **交际任务完成**：能否完成交际任务。

### TOPE C：演讲与问答评分标准

用户上传的 C 评分表按 1–6 级描述以下三方面：
1. **话题内容与论述**：切题程度、观点、论述合理性、逻辑清晰度及独特视角。
2. **词汇语法及语音语调**：词汇丰富度与准确性、语法准确性、语音语调。
3. **时间控制**：能否在规定时间内完成演讲。

C 表格标题为“演讲与问答”，但上传的等级条目没有给出单独的 Q&A 权重或独立问答分档。TOPE Mate 可以针对 C Q&A 阶段提供产品内部的回答相关性、解释充分度和文本语言反馈，但不声称这是截图中单列的官方 Q&A 评分项。

以上是对用户上传截图的结构化摘要，不是官方评分表逐字全文。官方 1–6 级只作为定性评价锚点；不把等级换算为百分制。

## 2. TOPE Mate 产品内部练习参考分

`TOPE Mate Practice Score` 是产品内部的 0–100 单阶段练习参考分，用于帮助学生观察同类练习中的变化。当前模块不把 B/C 多个阶段的分数合成为完整考试总分。它不是人大官方成绩、官方等级换算或正式考试预测。

产品内部细分维度、权重和 0–100 分锚点是初始实验设计，不是人大官方权重。分阶段配置见 `data/practice_score_policy.json`。

## 3. 产品内部维度与证据边界

| 维度 | 可观察内容 | 限制 |
|---|---|---|
| `relevance` | 回答是否切题、观点是否回应任务 | 不因合理立场不同扣分 |
| `organization` | 结构、顺序、衔接 | 自我介绍/问答不强制演讲结构 |
| `development` | 理由、解释、例子及论述充分度 | PEEL 只用于 B statement/C speech 的辅助反馈 |
| `language` | 转写可观察的词汇、语法和表达 | 不能从文本判断发音、语调、停顿或音频流利度 |
| `interaction` | 回应其他考生、衔接观点、提问和推进讨论 | 必须有目标考生及至少一位其他考生的真实带标签轮次；考官轮次不算同伴互动证据 |
| `taskCompletion` | 是否完成当前阶段任务 | 需结合题目/任务卡判断 |
| `timeManagement` | 录音时长与目标时长的偏差 | 必须提供 `targetDurationSeconds`，由后端固定产品规则计算 |

## 4. 总分算法

AI 只对当前阶段可评估的维度给出 0–100 整数分、理由及证据。服务端按固定产品权重计算：

`practiceScore = round(Σ(score × weight) / Σ(assessed weight))`

未评估维度必须为 `null`，从分子和分母中排除，并降低 `scoreCoverage.coveragePercent`。不能将未评估维度按 0 分处理。没有任何可评估维度时，总分为 `null`。

模型把某个可评估维度写成 `null`（录音太短、文本证据不足时的常见输出）按未评估处理：该维度出现在 `scoreCoverage.notAssessedDimensions` 与 `unassessed` 里，`scoreStatus` 变为 `partial`，不因此判整份报告无效。仍然 fail closed 的两条：给了分数就必须给文字解释；所有可评估维度都没有分数时返回 `INVALID_MODEL_OUTPUT`（诊断规则名 `NO_ASSESSABLE_DIMENSION_SCORE`），不产出练习分。

时间控制分由后端根据 `durationSeconds` 与 `targetDurationSeconds` 的固定规则计算，不由模型自由估分；这也是产品内部规则，不是官方时间换算。

## 5. 版本与纵向比较

历史练习只在评分算法版本、提示词版本、模型标识、考试类型、阶段、已评估维度和适用目标时长一致时，才使用相同的 `scoreCoverage.comparisonKey`。即使条件相同，不同题目的难度、熟悉度仍可能不同，分数只适合粗略观察趋势，不应理解为精密测量。

`officialAssessment.level` 永远为 `null`。界面展示 `practiceScore` 时必须标注“练习参考分（非官方）”。`overall.score` 只是兼容字段，等于 `practiceScore`。
