# TOPE Mate Practice Score 方法说明 v1.0.0

## 1. 定位

`TOPE Mate Practice Score` 是产品内部的 0–100 练习参考分，用于帮助学生比较相同考试类型、阶段和证据覆盖条件下的练习表现趋势。

当前 `practiceScore` 是单个考试阶段（stage）的练习分，不是 TOPE B/C 完整多阶段考试的合成总分。

它**不是**：
- 人大官方考试成绩；
- 人大官方 1–6 级的百分制换算；
- 对正式考试等级或成绩的预测；
- 经过真人考官大样本校准的测量量表。

人大官方 B/C 1–6 级描述继续作为定性评价锚点。产品内部的维度、权重、数值锚点和时间规则均为 TOPE Mate 初始设计，不是官方评分权重。

## 2. 计算方式

1. AI 根据题目、转写文本和可用的互动轮次，对当前阶段可评估的维度给出 0–100 整数分，并提供理由及原文证据。
2. 评分服务根据固定的阶段权重计算总分，AI 不得自行计算总分或改变权重。
3. 若某维度缺少必要证据，该维度为 `null`，不按 0 分处理。
4. 总分只使用已评估维度，并按这些维度的权重总和重新归一化：

   `practiceScore = round(sum(dimensionScore × dimensionWeight) / sum(assessedDimensionWeight))`

5. `scoreCoverage.coveragePercent` 表示本次实际参与总分计算的权重占该阶段配置总权重的比例。
6. 若没有任何可评分维度，`practiceScore` 为 `null`。

## 4. 0–100 维度分锚点

- 90–100：该维度表现持续突出，证据充分，几乎没有明显缺口。
- 80–89：表现扎实，主要要求均能做到，仅有少量不足。
- 70–79：整体有效、清楚，仍有可识别的改进空间。
- 60–69：完成主要要求，但表现不够稳定或存在明显缺口。
- 50–59：只部分满足要求，存在较明显不足。
- 35–49：多项关键要求完成不足，证据较少或偏离任务。
- 0–34：几乎没有展示该维度要求，或回答严重偏题/无法支持判断。

这些是产品内部的维度锚点，不与官方 1–6 级逐一对应。

## 5. 缺失证据与可比性

- 只有转写文本时，语言维度只评价词汇、语法和文本可观察表达；发音、语调、停顿、音频流利度标记为未评估。
- B 小组讨论只有在提供 `assessedSpeaker`，且 `speakerTurns` 同时包含该考生与至少一位其他参与者时，才评估互动能力。
- 只有提供 `targetDurationSeconds` 时，才评估时间控制。时间分由后端依据录音时长与目标时长的固定产品规则计算。
- 缺失维度不按 0 分处理；总分按已评估维度权重重新归一化。
- `scoreCoverage.comparisonKey` 仅在评分算法版本、提示词版本、模型标识、考试类型、阶段、已评估维度及适用的目标时长一致时相同。
- 即使 comparisonKey 一致，不同题目的主题熟悉度和难度仍可能不同，因此分数只适合观察趋势，不应被理解为精密测量。

## 6. 版本与校准

当前权重与时间规则为 `practice_index_v1.0.0` 初始实验版本；系统提示词版本为 `tope_practice_prompt_v0.6.0`。分数比较还要求模型标识一致。模型标识、提示词版本、权重或算法任一变化，比较键都会改变；完成真实模型验证和人工样本复核后再调整，避免新旧分数被直接混比。
